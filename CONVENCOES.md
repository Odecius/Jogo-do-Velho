# Convenções do projeto

- Documentação operacional em português do Brasil.
- Código, namespaces, classes, métodos e endpoints em inglês.
- Namespace base: `Abc.JogoDoVelho`.
- Nullable reference types e implicit usings habilitados.
- Warnings tratados como erros.
- Commits no formato `tipo: descrição curta`.
- Branch principal: `main`.
- CSS e JavaScript vanilla, sem framework sem justificativa registrada.
- Datas internas em UTC; timezone operacional `Europe/London`.
- Segredos e dados locais fora do Git.
